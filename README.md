# OrangeFox Action Builder
Compile your first custom recovery from OrangeFox Recovery using Github Action.

# How to Use
1. Fork this repository.

2. Go to `Action` tab > `All workflows` > `OrangeFox-Compile.yml/Build_fox.14.1.yml` > `Run workflow`, then fill all the required information:

* This action will now only support manifest 14.1 and 12.1
